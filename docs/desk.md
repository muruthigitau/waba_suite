# WhatsApp in Desk

The chat portal is where conversations happen. Desk — the normal back office — holds the settings, the
records and a quick way to send a template from any document.

## The WhatsApp workspace

Open the **WhatsApp** tile on the apps screen. The workspace collects the most used places:

- **Setup** — WhatsApp settings, WhatsApp accounts and labels,
- **Chatbot** — chatbot settings, keyword rules and flows,
- **Reports** — the two reports described in [Reports](reports.md),
- **Messaging** — templates, bulk messages, recipient lists and the message list,
- **Shortcuts** — direct links to the settings, accounts and message list.

An icon in the Desk navigation bar opens the chat portal in a new tab, so you can jump between the two.

## Send To Whatsapp from a record

Every record in Desk has an extra menu entry: **Send To Whatsapp**. Use it to send a template about
that record without leaving the page — an invoice to a customer, a quotation to a lead, a delivery
note to a supplier.

1. Open the record.
2. Choose **Send To Whatsapp** from the form menu.
3. Pick the WhatsApp number to send from and the template.
4. Check the phone number. If the record has a phone field, it is filled in automatically; you can
   change it.
5. Check the template values. Values that come from the record are shown and can be adjusted.
6. Optionally attach a PDF: choose a print format and letterhead, or pick a file already attached to
   the record.
7. Press **Send Now**.

When the message has gone out, a note is added to the record's timeline so the rest of the team knows
the customer was contacted. If sending fails, an error message appears — check the WhatsApp message
list for the reason.

This route always sends a template, so it works regardless of the 24-hour rule.

## The message list

**WhatsApp Message** is the record of every message in and out. Each row shows the contact, the
direction, the account, the time, and the status: sent, delivered, read or failed.

Open a message to see its content, the file it carried, and the conversation it belongs to. When a
message fails, the reason is written to the site's error log, which an administrator can read. This is
the place to look when:

- a customer says they never received a message,
- a campaign reports failures,
- you need to prove what was sent and when.

The list is long on a busy account; filter by date, contact, account or status before scrolling.

## Templates, accounts and labels

These are ordinary Desk records, which is convenient when you have many:

- **WhatsApp Templates** — the approved messages, with their preview and current state.
- **WhatsApp Account** — one record per business number, with its connection details and the team
  members assigned to it.
- **WhatsApp Chat Label** — the coloured labels offered in the chat portal.

Administrators can edit them here; agents normally only use them.

## Bulk messages and recipient lists

Campaigns and lists created in the chat portal also appear in Desk as **Bulk WhatsApp Message** and
their recipient lists. Desk is the better place to review a long campaign, correct a number in a list,
or check which messages failed.

## A sensible split

| Task | Better place |
| --- | --- |
| Reading and answering chats | Chat portal |
| Organising chats with labels, pins, stars | Chat portal |
| Sending a promotion | Chat portal, **Bulk** |
| Sending a template about one record | Desk, **Send To Whatsapp** |
| Checking a failed message | Desk, message list |
| Changing settings or users | Desk |
