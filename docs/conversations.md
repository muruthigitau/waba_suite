# Conversations

This page covers what happens inside a conversation: sending messages and files, replying, reacting,
and the one WhatsApp rule that catches everybody out — the 24-hour window.

## Sending a message

Type in the box at the bottom and press Enter. Messages appear in the conversation straight away.

## Sending files

Use the attachment button next to the message box to send a photo, video, document or audio file. You
can add a short caption before sending. Incoming files from customers are shown in the conversation
and can be opened or downloaded.

There are practical size and format limits set by WhatsApp. Very large files are refused by WhatsApp,
not by this app — compress the file or share a link instead.

## Replying and reacting

- **Reply** to a specific message so the customer knows which one you mean. The reply shows the
  original quoted above your answer.
- **React** with an emoji by choosing the reaction option on a message.
- Use the emoji picker for emojis inside your text.

Reactions are sent as WhatsApp reactions. They still count as a message to WhatsApp, so they follow the
same 24-hour rule as normal text.

## Sent, delivered, read

Under each outgoing message you will see its state:

| Shown as | Meaning |
| --- | --- |
| Sent | WhatsApp accepted the message |
| Delivered | It reached the customer's phone |
| Read | The customer opened the chat |

A tick that never moves past *Sent* usually means the customer's phone is offline — WhatsApp keeps the
message for a while and delivers it later.

Messages can also end up **Failed**. That normally means the number is not on WhatsApp, the account
has a problem, or WhatsApp rejected the content. Ask your administrator to check the message list in
Desk.

## The 24-hour rule

WhatsApp only allows ordinary messages — text, photos, files, reactions — within **24 hours of the
customer's last message to you**.

After that, the conversation is closed for free-form chat and you can only send an **approved
template**. Templates are pre-written messages that WhatsApp has reviewed, and they are the way to
re-open a quiet conversation.

In the portal this is easy to recognise:

- a yellow banner says the contact is outside the 24-hour window and only template messages can be
  sent;
- the typing box is replaced by a single **Send Template Message** button.

Choose the template, fill in any values and send. As soon as the customer replies, the window opens
again and the typing box comes back.

The same rule applies to a brand-new number that has never written to you: start with a template, then
continue normally once they answer.

## Templates inside a conversation

Templates are not only for re-opening a chat — you can send one at any time, for example to share an
order confirmation with a picture header. Approved templates are listed in the template picker with a
preview before you send. See [Templates and flows](templates-and-flows.md).

## Keeping context

- The full history stays in the chat, so you can scroll back to earlier messages.
- Use the chat menu to add labels, star or pin a chat, or archive it when you are done
  ([The chat portal](chat-portal.md)).
- For quick notes for colleagues, use the label that matches the situation rather than renaming a chat.

## When a message does not arrive

1. Check the marker under the message.
2. Ask the customer whether they can see it — some phones delay notifications.
3. If it says *Failed*, note the time and ask your administrator to look at the message in Desk.
4. If the typing box has disappeared, you are outside the 24-hour window: send a template.
